# Physics-Informed Option Pricing Model

This project explores option pricing from a physics-inspired perspective using Python. It connects stochastic processes, numerical simulation, and quantitative finance concepts through a Jupyter notebook implementation.

## Methods
- Black-Scholes model
- Monte Carlo simulation
- Stochastic differential equations
- Numerical visualization
- Sensitivity analysis over volatility, strike price, time to maturity, and interest rate

## Why this project
As a physics Ph.D. student, I wanted to connect tools I use in detector simulation and stochastic modeling to problems in quantitative finance.

## Files
- `Physics-Informed Option Pricing Model.ipynb`: main notebook

## Tools
Python, NumPy, SciPy, Pandas, Matplotlib, Jupyter
